## 활동 분야와 적용 사례

Hugo, Git, GitHub Pages를 사용해 개인 프로필 웹사이트를 제작하고 실제 배포에
적용했습니다.

## 활동 시기와 진행 상태

2026년 10월에 시작했으며, 프로필과 이미지 수정 및 1차 배포를 완료했습니다.
현재는 Blog와 About 페이지를 개선하고 새로운 기능을 추가하고 있습니다.

## 활동 목적

학업과 관심 분야를 소개하고, 웹사이트 제작과 배포 과정을 직접 이해하고
경험하는 것을 목표로 했습니다.

## 본인의 역할

프로필 정보 작성, 이미지 교체, JSON 파일 수정, About 페이지 작성, Git commit과
push, GitHub Actions 배포 확인을 직접 수행했습니다.

## 수행 과정과 선택 이유

Hugo Gruvbox 테마를 선택한 뒤 원본 예시 정보를 본인 정보로 교체했습니다.
반응형 레이아웃, 검색 기능, CV 구조와 다크·라이트 모드가 개인 콘텐츠와
배포 과정에 집중하기에 적합하다고 판단했습니다.

GitHub Pages와 GitHub Actions를 사용해 수정 내용을 실제 웹사이트에
반영했습니다.
