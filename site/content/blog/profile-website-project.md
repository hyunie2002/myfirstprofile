## Field and Application

I built a personal profile website using Hugo, Git, and GitHub Pages,
and deployed it publicly.

## Timeline and Progress

I started the project in October 2026 and completed the profile and image
updates, as well as the first deployment. I am currently improving the Blog
and About pages and adding new features.

## Purpose

I created this project to introduce my academic background and interests,
and to understand and experience the process of building and deploying a
website.

## My Role

I wrote the profile information, replaced the profile image, edited the JSON
file, created the About page, performed Git commits and pushes, and checked
the GitHub Actions deployment.

## Process and Rationale

I selected the Hugo Gruvbox theme and replaced its example information with
my own. I used GitHub Pages and GitHub Actions to apply the changes to the
deployed website.

I chose the Hugo Gruvbox theme because its responsive layout, search function,
CV structure, and dark/light mode provided a useful base for focusing on my
own content and deployment.

## Results

I completed a personal profile website and verified the result at its GitHub
Pages address.

- Site: <https://hyunie2002.github.io/myfirstprofile/>

## Learning Outcomes and Future Improvements

I learned about JSON file structures and the Git workflow. In the future, I
plan to improve the mobile responsive layout, menu navigation, and keyboard
accessibility.
