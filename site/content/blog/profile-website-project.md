## 활동 분야와 적용 사례

Hugo, Git, GitHub Pages를 사용해 개인 프로필 웹사이트를 제작하고
실제 배포에 적용했다.

## 활동 시기와 진행 상태

2026년 10월에 시작했으며, 프로필과 이미지 수정 및 1차 배포를 완료했다.
현재는 사이트의 blog, about 페이지와 추가 기능을 개선하고 있으며 진행중에 있다.

## 활동 목적

본인의 학업과 관심 분야를 소개하고, 웹사이트 제작과 배포 과정을 직접
이해하기 위해서, 경험하기 위해 진행했다.

## 본인의 역할

프로필 정보 작성, 이미지 교체, JSON 파일 수정, About 페이지 작성,
Git commit과 push, GitHub Actions 배포 확인 등을 직접 수행했다.

## 수행 과정과 선택 이유

Hugo Gruvbox 테마를 선택한 뒤 원본 예시 정보를 본인 정보로 교체했다.
GitHub Pages와 Actions를 사용해 수정 내용을 실제 웹사이트에 반영했다.

## 결과물

개인 프로필 웹사이트를 완성했고, GitHub Pages 주소에서 결과를 확인했다.

- 사이트: <https://hyunie2002.github.io/myfirstprofile/>
- 저장소: <https://github.com/hyunie2002/myfirstprofile>

## 학습 결과와 개선 방향

JSON 파일 구조와 Git 작업 과정을 익혔다. 앞으로 모바일 반응형 화면,
메뉴 이동과 키보드 접근성을 개선할 예정이다.
