## 나에 대하여

저는 전북대학교 컴퓨터공학과에서 공부하고 있는 이창현입니다.

정치외교학을 공부한 뒤 컴퓨터공학으로 전공을 변경했으며, 현재는 웹 개발과
사이버보안을 공부하고 있습니다.

## 관심 분야

저는 웹 개발과 사이버보안에 관심이 있습니다.

웹 개발 기초와 함께 HTML, CSS, JSON, Hugo, Git, GitHub와 GitHub Actions를
공부하고 있습니다.

AI 기술이 발전할수록 웹 개발 지식이 AI 활용에 효율성을 제공할 수 있다고
생각합니다. 또한 다루는 정보량이 많아질수록 사이버보안의 중요성도 커질
것이라고 생각해 이 분야에 관심을 갖게 되었습니다.

## 제작 목적

이 사이트는 저의 학업, 관심 분야, 학습 과정과 프로젝트 활동을 정리하기 위해
제작했습니다.

Hugo 테마를 활용해 개인 프로필 사이트를 만들고 GitHub Pages로 배포하는
과정을 직접 수행했습니다.

앞으로는 AI를 활용해 직접 사용할 수 있는 웹사이트나 프로그램을 만드는 것을
학습 목표로 삼고 있습니다. 이번 초급 프로젝트와 포트폴리오 제작을 통해
기본적인 웹사이트를 완성하고, 이후에는 인프런과 같은 학습 플랫폼에서
보안과 웹 개발을 더 공부할 계획입니다.

## 코드

Hugo Gruvbox 테마의 기본 구조를 바탕으로 다음 내용을 직접 수정했습니다.

- 프로필 정보
- 프로필 이미지
- 교육 정보와 기술 정보
- GitHub 프로필 링크
- 사이트 콘텐츠

원본 테마의 구조를 참고했으며, 최종 내용과 설정은 개인 사이트에 맞게
수정했습니다.
